# 知识共享后台系统 测试点分析

> 分析方法：按"模块 → 接口 → 功能点/校验点"逐层拆解；每个接口从 **正常场景、参数校验（等价类+边界值）、鉴权与越权、异常与安全、数据一致性** 五个维度展开。

## 一、测试点分析总纲（五维度）

| 维度 | 关注点 | 示例 |
|---|---|---|
| 功能正确性 | 主流程能否走通、返回数据是否正确 | 注册成功、列表只含已审核知识 |
| 参数校验 | 非空、长度边界（6位）、格式、唯一性 | 密码5位拒绝、6位通过；重复邮箱拦截 |
| 鉴权与越权 | 未登录、普通用户调管理员接口、操作他人数据 | 未登录发布→"请先登录"；删他人知识被拒 |
| 异常与安全 | 非数字ID、SQL注入、请求方法、敏感信息 | id=abc 不应500；GET不应提交敏感操作 |
| 数据一致性 | 状态流转、级联删除、浏览量统计 | 删除知识后收藏记录同步清理 |

## 二、分模块测试点

### 模块1 注册（/register）
- **功能**：合法数据注册成功，flag=success；数据库新增 role=0 记录。
- **参数校验（等价类/边界值）**：
  - username：为空 / 全空格（trim 校验）/ 正常 / 已存在（重复用户名）
  - password：5位（无效边界）/ 6位（有效边界）/ 与 confirmPassword 不一致
  - email、phone：为空（可空）/ 已存在（唯一性）/ **格式合法性（发现缺陷）**
- **安全**：请求方法未限制，GET 可提交（敏感信息进 URL）；密码明文传输。
- **产出用例：12 条**

### 模块2 登录（/login）
- **功能**：用户名/邮箱/手机号三种等价类登录均成功；响应体含 id/username/role；Session 建立（Set-Cookie: JSESSIONID）。
- **参数校验**：username 为空 / password 为空 / 用户不存在 / 密码错误（含大小写敏感验证）。
- **安全**：GET 方式提交；SQL 注入探测（`' or '1'='1`，PreparedStatement 预编译应拦截）。
- **产出用例：9 条**

### 模块3 登出（/logout）
- **功能**：登录后登出返回成功；未登录登出不报错（幂等）。
- **鉴权联动**：登出后携带原 Cookie 访问需登录接口 → "请先登录"，验证 Session 已销毁。
- **产出用例：3 条**

### 模块4 知识列表（/knowledge?action=list）
- **功能**：仅返回 status=1；按 create_time 倒序；字段完整性（title/content/category/viewCount/publisherName）。
- **鉴权**：游客可访问。
- **性能隐患**：无分页参数，数据量大时全量返回（提优化建议缺陷）。
- **产出用例：5 条**

### 模块5 知识详情（/knowledge?action=detail）
- **功能**：正常查询；**view_count 连续查询两次应 +1**（累加校验）。
- **参数校验**：id 不传 → "知识ID不能为空"；id 不存在 → "知识不存在"；**id 非数字 → 当前 HTTP 500（缺陷）**。
- **越权/泄露**：待审核/未通过知识通过 id 直查可返回详情（信息泄露缺陷，遗留）。
- **产出用例：6 条**

### 模块6 发布知识（/knowledge?action=publish）
- **功能**：登录后发布成功，状态=待审核，不出现在公开列表、出现在"我的发布"。
- **参数校验**：title 空 / title 全空格 / content 空。
- **鉴权**：未登录 → "请先登录"。
- **产出用例：6 条**

### 模块7 我的发布（/knowledge?action=myKnowledge）
- **功能**：仅返回本人知识（含待审核/通过/拒绝三种状态）；按时间倒序。
- **隔离性**：与他人数据无交叉。
- **鉴权**：未登录拦截。
- **产出用例：3 条**

### 模块8 删除自己的知识（/knowledge?action=delete）
- **功能**：删除本人知识成功；列表与我的发布中同步消失。
- **越权**：删除他人知识被拒（"只能删除自己发布的知识"）；id 不存在同样拒绝。
- **参数校验**：id 缺失 → "知识ID不能为空"；id 非数字 → 500（缺陷）。
- **级联**：删除后该知识的 favorite 记录应被清理。
- **产出用例：7 条**

### 模块9 收藏/取消收藏/我的收藏（favorite add/remove、myFavorites）
- **功能**：收藏成功 → 重复收藏拦截（"已经收藏过了"）→ 取消收藏 → myFavorites 不再显示（完整闭环）。
- **数据校验**：**收藏不存在的 knowledgeId 返回成功（缺陷）**；favAction 非法值 → "参数类型错误"；knowledgeId 缺失提示。
- **状态过滤**：myFavorites 仅显示 status=1 的收藏（知识被拒后从收藏视图消失）。
- **幂等性**：取消未收藏的知识也返回"取消收藏成功"（设计如此，按通过处理并备注）。
- **产出用例：13 条**

### 模块10 个人信息（/user?action=updateInfo / updatePassword）
- **功能**：修改邮箱/手机号成功且重新登录生效；修改密码后旧密码失效、新密码生效。
- **参数校验**：新密码 5 位拒绝 / 6 位通过（边界）；旧密码错误 → "原密码错误"；不传 oldPassword → "原密码错误"。
- **异常**：邮箱与他人重复触发数据库唯一约束 → 仅提示"修改失败"（体验缺陷）；邮箱格式不校验（缺陷）。
- **鉴权**：未登录 → "请先登录"。
- **产出用例：11 条**

### 模块11 管理员-知识审核（pending / audit approve|reject / adminDelete）
- **功能**：管理员登录 role=1；待审核列表仅含 status=0；审核通过 → 公开列表可见；拒绝 → 不可见。
- **越权（重点）**：未登录、普通用户访问 pending/audit/adminDelete → "无权限"。
- **参数校验**：id 不存在 → "审核失败"/"删除失败"；id 非数字 → 500（缺陷）。
- **业务规则缺陷**：auditAction 非法值按"拒绝"处理；已审核知识可被重复审核。
- **级联**：adminDelete 删除知识后，其他用户对该知识的收藏记录同步删除。
- **产出用例：15 条**

### 模块12 管理员-用户管理（/admin/user 列表/update/delete）
- **功能**：用户列表完整且不泄露 password 字段；修改用户 email/phone 成功；删除用户成功。
- **越权**：未登录、普通用户 → "无权限"。
- **自我保护**：管理员删除自己 → "不能删除自己"。
- **参数校验**：id 缺失 / id 不存在 / id 非数字（500 缺陷）。
- **级联一致性（重点）**：删除用户后——其收藏记录清空、其发布知识全部删除、被删知识对应的他人收藏也清空、被删用户无法再登录。
- **产出用例：14 条**

### 模块13 通用/其他
- 未知 action 提示"未知操作"；响应统一 JSON 结构（flag+data）；HTTP 状态码 200（异常场景除外）。
- **产出用例：4 条**
