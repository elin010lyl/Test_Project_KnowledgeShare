## 二、核心数据

- 接口 21 个，模块 13 个，用例 **109 条**（P0 50 / P1 41 / P2 18）；
- 第一轮：通过 92 / 失败 17，通过率 **84.4%**；
- 缺陷 **10 个**（严重 2 / 一般 4 / 轻微 3 / 建议 1），8 个修复关闭，2 个评审遗留；
- 第二轮回归：通过 107 / 109，通过率 **98.2%**，严重缺陷清零，结论"同意发布"；
- 自动化：pytest+requests+Allure 分层框架，10 个测试类 96 条用例，接口覆盖率 100%。

## 三、使用说明

1. **姓名替换**：Excel 用例与缺陷报告中的 `tester01` 替换为本人姓名/花名，执行日期按需微调；
2. **演示被测系统**：需要本地 Tomcat 9 + MySQL 8 部署 `knowledge_sharing_system`（库 knowledge_share，预置账号 testuser1/123456、admin/admin123）；
3. **演示自动化**：见 [02_接口自动化/README.md](02_接口自动化/README.md)，`pip install -r requirements.txt` 后执行 `pytest`，再 `allure serve reports/allure-results` 看报告；
4. **建议展示顺序**：项目概述 → 用例 Excel（挑 2‑3 条展开）→ 缺陷单 → 源码修复建议文档 → Allure 报告截图 → 总结报告准出结论。
